# Classifieds Board

A retro 90s/SWF4 style local message board with no email verification.

## Features
- ✅ No email required - just username and password
- ✅ SWF4 / classic windows aesthetic with little box post layout
- ✅ Location-based proximity sorting (uses browser geolocation)
- ✅ Posts automatically expire after 7 days
- ✅ Posts self-destruct after 10 views
- ✅ 140 character limit - spec only, no fluff
- ✅ All data stored locally in browser

## How to run
```
npm install
npm run dev
```

## How to build
```
npm run build
```
