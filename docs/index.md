# NychForge Documentation

## Philosophy
Bounded recursive self-editing AI using ADSR gating and Nych symbolic protocol.

## Core Workflow
1. Define agent + traits in `.mg8`
2. Run recursive optimization with ADSR control
3. Use Timeline to find sweet spot
4. Export Builder APK (editable) or Runtime APK (locked)

## Key Components
- **ADSR Gating** — Controls optimization intensity over time
- **Nych Protocol** — Symbolic self-modification language
- **Timeline** — Version history & branching
- **APK Exporter** — Mobile deployment (Builder + Runtime)
